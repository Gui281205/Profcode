Oque é Html?

Por ser muito utilizada no desenvolvimento de sites, é comum pensar que HTML seja uma linguagem de programação. No entanto, o HTML é uma linguagem de marcação, e não de programação. Mas por que isso acontece? Linguagens de programação foram projetadas para criar algoritmos, manipular variáveis, estruturas de dados, entre outras coisas, enquanto o HTML (HyperText Markup Language, que em português significa Linguagem de Marcação de Hipertexto) é utilizado para estruturar e formatar o conteúdo de páginas web. Para ser possível construir um projeto com essa tecnologia, precisamos de um arquivo com formato `.html`, sendo assim possível abri-lo em um navegador, que interpretará o código-fonte para dispor os elementos na tela.

O que posso criar com html?

Com o HTML você pode criar vários elementos para construir uma página web com o tema da sua preferência:

  • Textos
  • Imagens
  • Vídeos
  • Áudios
  • Links
  • Formulários
